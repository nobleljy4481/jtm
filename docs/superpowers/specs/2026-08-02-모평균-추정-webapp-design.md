# 모평균 추정 인터랙티브 학습 웹앱 — 설계 문서

- 작성일: 2026-08-02
- 대상: 고등학교 「확률과 통계」 - 모평균의 추정 단원
- 산출물: `index.html` 단일 파일 (외부 서버 없이 브라우저에서 바로 실행)

## 1. 목적

학생이 다음 10가지를 **직접 조작하고 시각적으로 탐구**하며 이해하는 인터랙티브 코스웨어를 만든다.

1. 표본평균의 분포
2. 표준화(Z)의 의미
3. 신뢰구간 공식의 유도 과정
4. 실제 표본이 추출되는 방식
5. 표본평균 계산 과정
6. 신뢰구간 계산 과정
7. 오차한계(Margin of Error)의 의미
8. 신뢰도와 신뢰구간 폭의 관계
9. 표본크기와 신뢰구간 폭의 관계
10. 신뢰구간의 참된 의미 (95%의 확률적 의미)

단순 계산기가 아니라, 교사가 별도 설명 없이 화면만으로 개념을 지도할 수 있는 수준을 목표로 한다.

## 2. 학습 흐름 (탭 구조와 학습목표 매핑)

> **업데이트(이후 반영)**: TAB2(표본추출 Visualizer)와 TAB3(반복 시뮬레이션)를 하나의 탭으로 통합했다. 탭이 4개→3개가 되었고, 통합된 TAB2 안에서 위쪽에 1회 상세 과정(구 TAB2), 아래쪽에 반복 시뮬레이션(구 TAB3)이 세로로 이어진다. 가로 폭은 태블릿 2열 그리드를 유지하고 세로 스크롤로 내려가며 본다. 아래 표/설명은 이 통합 전 초기 구조 설명이며, §5의 TAB2·TAB3 절이 통합 후 최신 구조를 반영한다.

| 탭 | 내용 | 학습목표 |
|---|---|---|
| TAB 0 | 모집단 이해 | 1 |
| TAB 1 | 신뢰구간 공식 유도 (Step1~5 + 확인 예제) | 2, 3, 7, 10 |
| TAB 2 | 표본추출 Visualizer (1회 상세 과정) | 4, 5, 6, 7 |
| TAB 3 | 반복 시뮬레이션 (+고급 옵션) | 8, 9, 10 |

TAB0 → 1 → 2 → 3 순서로 진행하도록 유도하되, 탭 이동 자체는 자유롭게 허용한다.

## 3. 모집단 데이터

- 앱 시작 시 정규분포 N(240, 40²)을 따르는 학생 1,000명의 하루 스마트폰 사용시간(분) 데이터를 생성한다.
- 각 학생은 `{ id, minutes }`를 가진다.
- 모집단은 메모리(전역 상태)에 유지되며, TAB0/TAB2/TAB3 전체가 공유한다.
- 표본추출은 **복원추출**로 진행한다 (모집단이 유한(1,000명)이고 표본크기가 최대 200까지 가능해, 비복원추출 시 유한모집단수정계수가 필요해지는 교육과정 밖의 문제가 생기기 때문. 매번 독립적으로 뽑는 교과서 가정을 유지).

## 4. 전역 상태 아키텍처

```js
state = {
  mu: 240, sigma: 40, populationSize: 1000, seed: null,
  population: [],            // TAB0에서 생성, 전 탭이 참조
  sampleSize: 20,            // 10~200
  confidenceLevel: 95,       // 95 | 99
  currentSample: null,       // TAB2 최근 표본 상세 결과
  history: [],               // TAB3 누적 시행 목록
}
```

- **모집단 재생성**: TAB0의 "모집단 다시 생성" 버튼과 TAB3 고급 옵션(모평균/모표준편차/모집단크기/시드 변경)이 동일한 `regeneratePopulation()`을 호출한다. 재생성 시 `currentSample`과 `history`를 초기화하고, "모집단이 바뀌어 누적 결과가 초기화됩니다"라고 안내한다.
- **TAB2 → TAB3 연동**: TAB2에서 "표본 1회 추출"을 실행하면 그 결과가 `history`에도 한 건 자동으로 추가되어 TAB3의 누적 시행 횟수에 반영된다. TAB2와 TAB3는 같은 추출 로직을 공유하되, TAB2는 항상 풀 애니메이션으로, TAB3는 설정된 속도로 재생한다.
- 렌더링은 상태 변경 시 해당 탭의 순수 render 함수만 다시 그리는 방식으로 처리한다. 수식은 DOM 삽입 후 `MathJax.typesetPromise()`로 재렌더링한다.

## 5. 탭별 상세 설계

### TAB 0 — 모집단 이해
- 히스토그램(평균선, ±1σ, ±2σ 표시), 도트플롯(1,000명을 점으로, 선택된 표본은 파란색 강조), 통계량(평균/표준편차/최솟값/최댓값)
- "모집단 다시 생성" 버튼 (§4의 `regeneratePopulation()` 사용)

### TAB 1 — 신뢰구간 공식 유도
Step Card 방식, 총 5단계 + 확인 예제.

- **Step1**: 표본평균의 분포 $\bar X \sim N(\mu, \sigma^2/n)$ 설명
- **Step2**: 표준화 $Z = \dfrac{\bar X - \mu}{\sigma/\sqrt n}$
- **Step3**: 표준정규분포 곡선을 Canvas로 직접 그리고, **95%/99% 2단계 토글**로 곡선 아래 면적과 z값(1.96 / 2.58)이 전환됨
- **Step4**: 부등식 변형을 애니메이션으로 한 줄씩 전개 (다음 버튼을 눌러야 다음 줄이 나타남 — 한 번에 다 보여주지 않음)
- **Step5**: 95%/99% 최종 공식 비교, 오차한계 공식 $ME = z\dfrac{\sigma}{\sqrt n}$ 설명
- **확인 예제 (신규)**: Step5 뒤에 고정된 숫자를 대입해보는 연습 단계. 예: "모표준편차가 8인 모집단에서 크기 64인 표본을 임의추출했더니 표본평균이 50이었다. 신뢰도 95%의 신뢰구간을 구하시오." → 학생이 공식에 대입하는 과정을 단계별로 확인. 추상적 증명(TAB1)과 실제 랜덤 표본(TAB2) 사이를 잇는 다리 역할.

> z값은 교과서 관례에 따라 95%→1.96, 99%→2.58을 사용한다 (2.576이 아님).

### TAB 2 — 표본추출 & 신뢰구간 시뮬레이션 (구 TAB2+TAB3 통합)

아래 두 절(1회 상세 과정 / 반복 시뮬레이션)은 이제 **하나의 탭 안에서 위·아래로 이어진 섹션**이다. 탭 이동 없이 스크롤만으로 "표본 1개가 뽑히는 과정 → 그 결과가 누적되어 성공률이 되는 과정"을 한 흐름으로 볼 수 있게 하기 위함이다. 반복 시뮬레이션 섹션 시작 지점에 구분용 배너 카드("반복 시뮬레이션 — …")를 둔다.

#### 1회 상세 과정 (구 TAB2, 가장 중요한 섹션)
표본크기 슬라이더(10~200) → "표본 1회 추출" 버튼 클릭 시:
1. 모집단 도트플롯에서 선택된 학생들을 파란색으로 애니메이션 강조
2. 선택된 학생 목록(ID, 사용시간) 테이블 표시, 표본만 다시 그린 도트플롯
3. 표본평균 계산 과정 애니메이션 (합계 → ÷n → 표본평균)
4. 오차한계(ME) 단계별 계산
5. 신뢰구간 계산: 공식에 실제 숫자 대입 → 최종 구간
6. 구간을 선분으로 시각화, 모평균(240) 세로선 표시, 포함(초록)/미포함(빨강) 판정
7. 자동 해설 문구 ("이번 신뢰구간은 240을 포함합니다" 등)
8. 이 결과는 TAB3 `history`에도 자동 반영됨 (§4)

#### 반복 시뮬레이션 (구 TAB3, TAB2 섹션 바로 아래로 이어짐)
- 설정: 표본크기, 속도
- 반복 횟수 입력: **숫자 입력창 + "추출" 버튼**으로 임의 횟수 지정 가능, 그리고 1회/10회/100회/자동/일시정지/초기화 프리셋 버튼도 병행 제공
- **고급 옵션 패널** (구 탐구모드 통합): 모평균, 모표준편차, 모집단 크기, 랜덤 시드를 자유롭게 변경 가능. 변경 시 `regeneratePopulation()` 호출
- **매 표본추출마다 95%와 99% 신뢰구간을 동시에 계산**한다 (`drawOneTrial()`이 `interval95`/`interval99`/`contains95`/`contains99`를 모두 기록). 신뢰도 선택 드롭다운은 없으며, 대신 아래 두 창을 함께 제어하는 보기 모드 버튼을 둔다: **"95%만" / "99%만" / "비교(95%+99%)"** (기본값: 비교) 순서로 배치.
- **창1(신뢰구간 비교)과 창2(성공률)를 좌우로 배치**하여 신뢰도에 따른 신뢰구간 길이 변화를 한눈에 비교할 수 있게 한다.
  - **창1**: Error Bar 막대 차트(Chart.js, 가로 floating bar). "비교" 모드에서는 회차마다 99% 구간(옅은 파란 배경, 굵게)과 95% 구간(포함/미포함에 따라 초록/빨강, 가늘게)을 같은 위치에 겹쳐 그려 폭 차이를 직접 비교한다. "95%만"/"99%만" 모드에서는 해당 구간만 단색으로 표시한다. 모평균 위치에 세로 점선과 "모평균 {mu}" 라벨을 표시한다. 회차가 많아지면 세로로 스크롤되는 영역 안에서 차트 자체 높이가 늘어난다(회차당 높이 고정, 잘리지 않음).
  - **창2**: "비교" 모드에서는 95%/99% 성공률을 텍스트로 나란히, 반원형 게이지 2개(95%/99% 각각)를, 누적 성공률 Line Chart도 95%(초록)·99%(파랑) 두 선을 동시에 그린다. 필터 모드에서는 해당 신뢰도 하나만 표시한다.
  - 두 창 모두 표본추출이 일어날 때마다(1회든 자동 반복 중이든) 매 회차 직후 즉시 다시 그려진다 — 시뮬레이션이 끝난 뒤 최종 결과만 보여주는 것이 아니라 진행 중 실시간으로 누적되는 모습을 보여준다.
- **애니메이션 정책**: 매 회차마다 "도트플롯 표본 강조(0.2~0.4초) + 신뢰구간 등장·판정"이라는 축약된 핵심 시각효과는 유지하되, "합계→÷n→평균", "공식 한 줄씩 전개" 같은 상세 계산 전개 애니메이션은 생략한다. "속도" 설정이 이 축약 애니메이션의 재생 속도를 조절한다. 이렇게 100회를 자동 재생해도 화면이 계속 움직이며 학생이 진행 상황을 체감할 수 있다.
- 매 회차 결과가 성공률에 수렴하는 것을 보여주는 것이 핵심 목적이므로(학습목표 10), 창1/창2를 나란히 두어 "신뢰도가 높을수록 구간은 넓어지지만(창1) 그만큼 포함될 확률도 높아진다(창2)"는 관계(학습목표 8)를 동시에 체감하게 한다.

TAB2는 독자적으로 신뢰도 95%/99% 토글 버튼을 가지며(계산 과정을 하나의 신뢰도로 상세히 보여주기 위함), 이 선택은 TAB3의 보기 모드와는 별개다.

## 6. 시각화 구현 방식

- 히스토그램, 도트플롯, 표준정규분포 곡선, 신뢰구간 선분 → **Canvas 2D 직접 구현** (세밀한 단계별 애니메이션 제어가 필요하기 때문)
- Error Bar(floating bar), 누적 성공률 line chart, 원형 Gauge → **Chart.js**

## 11. 레이아웃 — 태블릿 가로 해상도 우선

- 학생들이 주로 태블릿을 가로로(예: 1024×768) 놓고 사용하므로, 각 탭 내부를 **2열 CSS Grid**로 구성해 세로 스크롤 없이 한 화면에 최대한 담는다.
- 넓은 시각화(히스토그램+도트플롯처럼 나란히 둘 수 있는 것 제외, TAB1 Step3 정규분포 곡선처럼 폭이 필요한 카드)는 `card full` 클래스로 2열 전체를 차지하고, 나머지 카드는 1열(절반 폭)을 차지해 자연스럽게 짝을 이룬다.
- 행 수가 늘어나는 목록(TAB2 표본 테이블, TAB3 창1 Error Bar 차트)은 카드 내부에 `max-height` + `overflow-y: auto` 스크롤 영역을 둬서, 표본크기·회차가 커져도 카드 자체가 화면 밖으로 밀려나지 않게 한다.
- 700px 이하 좁은 화면에서는 2열 그리드가 1열로 자동 전환된다.

## 7. 엣지 케이스 / 검증 규칙

- 자동/100회 모드에서는 §5 TAB3 애니메이션 정책에 따라 축약 애니메이션만 재생
- 고급 옵션에서 σ ≤ 0, populationSize < 최대 표본크기(200) 같은 비정상 입력 방지 (최소값 제한)
- 소수 표시 자릿수 통일: 평균·구간값은 소수 둘째 자리, z값은 소수 둘째 자리(1.96, 2.58)
- 모집단 재생성 시 누적 `history` 초기화 + 안내 문구 표시

## 9. 기술 스택 및 파일 구조

- HTML5 / CSS3 / Vanilla JavaScript (ES6+), 프레임워크 없음
- 산출물은 `index.html` 단 하나. 내부에 `<style>`과 `<script>`를 포함한다.
- 외부 CDN(MathJax, Chart.js, Pretendard)을 사용하므로 **인터넷 연결이 있는 환경에서 실행**해야 정상 동작한다 (완전 오프라인 더블클릭 실행은 전제하지 않음 — 사용자 요청에 따른 결정).

## 10. 검증 계획

- 브라우저에서 직접 열어 탭별 기능 동작 확인 (자동화 테스트 없음 — 정적 학습 자료 특성상 수동 검증)
- 각 반응형 브레이크포인트(1920/1440/1280/1024/태블릿)에서 레이아웃 확인
