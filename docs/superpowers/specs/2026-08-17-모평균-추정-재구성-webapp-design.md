# 모평균의 추정 — 교수학습 흐름 재구성 설계 문서

> 작성일: 2026-08-17
> 상태: 사용자 검토 대기 (커밋 안 함 — 로컬 파일로만 존재)

## 1. 배경

기존 `C:\dev\withjm`의 "모평균 추정" 웹앱(TAB0~2 구조)은 시뮬레이션 기능(표본 강조 산점도, 95%/99% 신뢰구간 비교, 반복 시뮬레이션 시각화, 누적 포함비율 그래프)이 잘 만들어져 있지만, 화면이 "모집단 이해 → 공식 유도 → 시뮬레이션" 순서로 구성되어 있어 통계적 추론의 필요성이 느껴지기 전에 답(모평균, 공식)이 먼저 보이는 문제가 있다.

한편 `C:\dev\first-task`의 "모비율 추정" 웹앱은 단계형(step-by-step) 진행 구조를 사용해 "현실적 문제 상황 → 점추정의 한계 체감 → 구간추정의 필요성 → 신뢰도 개념 → 공식 유도 → 검증 → 응용" 순서로 교수학습 흐름이 잘 설계되어 있고, 특히 표준정규분포 경계값 z를 슬라이더로 직접 탐색해서 찾는 활동이 있다.

이 문서는 **withjm의 시뮬레이션 기능을 그대로 보존**하면서, **first-task의 교수학습 흐름과 z 탐색 활동 구조를 이식**하여 하나의 새 웹앱으로 재구성하는 설계다. 결과물은 `C:\dev\jtm`에 만든다 (원본 두 프로젝트는 건드리지 않음).

## 2. 전체 아키텍처

- **파일 구조**: `index.html` / `style.css` / `script.js` 3분할 (사용자 기본 원칙 + first-task 구조 재사용). 모듈(`import`/`export`) 없음, 더블클릭으로 바로 열림.
- **화면 골격**: TAB 방식 폐기. first-task의 진행바(상단 스텝 인디케이터) + 하단 이전/다음 버튼 구조를 그대로 가져와 10단계로 재구성.
- **모평균 비공개 메커니즘**: `state.mu`는 처음부터 내부적으로 존재하고 계산·판정에 항상 쓰이지만, **8단계(반복 시뮬레이션) 진입 전까지는 화면에 숫자로 노출하지 않는다.** 신뢰구간 판정 막대·Error Bar 차트의 "모평균 240" 라벨 그리기 함수에 `reveal` 불리언 인자를 추가:
  - `reveal = false`: 점선 + "실제 모평균 위치 (비공개)" 텍스트만 표시, 숫자 없음
  - `reveal = true`: 기존처럼 "모평균 240" 숫자 라벨 표시
  - `state.meanRevealed` 플래그로 제어, 8단계 진입 시 `true`로 전환
- **시뮬레이션 로직 재사용**: `generatePopulation`, `mean`, `stdDev`, `sampleWithReplacement`, `confidenceInterval`, `Z_VALUES`, `drawHistogram`, `drawDotPlot`, `drawIntervalLine`, Error Bar/게이지/누적그래프 로직은 withjm 코드를 그대로 이식(Canvas 2D 직접 구현 방식 유지, Chart.js는 게이지·누적그래프에서만 계속 사용).
- **localStorage 저장**: first-task처럼 진행 상태·입력값을 저장할지는 선택사항 — 우선 포함(재사용이 쉽고 학생이 새로고침해도 진행상황 유지되는 장점).

## 3. 단계별 설계

### 1단계. 현실적 탐구 상황
- **목적**: 전수조사가 비현실적이라는 문제의식 조성, 모집단 전체는 아직 보여주지 않음
- **구성**: 서사 카드("고등학생 1,000명의 하루 스마트폰 사용시간이 궁금하지만 전수조사는 비용이 크다") + 예시로 학생 몇 명(예: 5~10명)의 표(ID·사용시간)만 제시 + "전체 평균이 얼마일지 예측해보라"는 숫자 입력칸
- **재사용**: first-task 1단계 문체·구조. 표는 withjm 스타일 테이블 재사용

### 2단계. 점추정의 한계
- **목적**: 표본을 뽑을 때마다 표본평균이 달라진다는 것을 체감
- **구성**: "표본 1개 뽑기" 버튼(n 고정, 예 20명) → 뽑을 때마다 표본평균이 작은 누적 점도표에 점으로 추가됨
- **재사용**: withjm의 `sampleWithReplacement`+`mean` 재사용. 누적 점도표는 first-task 2단계의 누적 차트 아이디어를 `drawDotPlot` 패턴으로 신규 구현(표본평균 값들을 점으로 누적)

### 3단계. 구간추정의 필요성
- **목적**: "점 하나보다 범위로 추정하는 게 낫지 않을까"라는 성찰 유도
- **구성**: 성찰 질문 + 서술형 입력창 (정답 판정 없음)
- **재사용**: first-task 3단계 그대로

### 4단계. 구간 길이와 모평균 포함 정도 탐구
- **목적**: 신뢰도/z 개념 도입 전에, "구간을 넓히면 실제 값을 포함할 확률이 높아진다"는 직관을 먼저 만들기
- **구성**: 표본평균 ± 임의 오차범위(숫자 슬라이더, z 아님) → "구간 1개 만들기" / "같은 방법으로 30회 반복하기" 버튼 → 반복 결과에서 "실제 모평균 위치(비공개 점선)"를 포함한 비율 표시(숫자 위치는 안 보여주고 포함 여부만 판정)
- **재사용**: first-task 4단계 구조(마진 슬라이더, 배치 실행, 포함율 텍스트, 폭-포함율 추이 그래프) 그대로, 계산은 withjm 스타일 함수로 대체. 모평균 라벨은 비공개 처리(2절 메커니즘 적용)

### 5단계. 신뢰도의 필요성 및 의미
- **목적**: "몇 %는 포함하도록 만들고 싶은가"라는 질문으로 신뢰도(95%/99%) 개념을 공식 도입
- **구성**: 설명 카드 (first-task 6단계 텍스트를 모평균 맥락으로 각색)

### 6단계. 표준정규분포를 이용한 신뢰구간 공식 유도
두 파트로 구성:
- **6-1. z 찾기**: first-task 7단계의 슬라이더 탐색 활동을 그대로 이식 — "95% 찾기/99% 찾기" 토글 + 경계값 슬라이더(0~3.5, 0.01 단위) + 표준정규분포 곡선(withjm의 `drawNormalCurve` 확장, 넓이는 수치적분으로 계산) + 가운데 넓이 실시간 표시 + 목표 근접 시 색상 변화와 "찾았습니다! z≈1.96일 때 가운데 영역이 0.95가 됩니다. 이 값이 95% 신뢰도의 신뢰구간에 쓰이는 값입니다" 메시지
- **6-2. 부등식 변형**: z를 찾은 직후 연결되어, withjm 옛 Step4의 "다음" 버튼식 전개를 확장 — 첫 줄은 방금 찾은 z값이 자동으로 채워져 표시되고, 대입 줄은 자동 공개, 마지막 "m에 대해 정리한 최종 신뢰구간 식"은 객관식(부호/방향이 다른 오답 포함)으로 확인하도록 함 (이전 대화에서 합의된 C안)

### 7단계. 한 표본의 신뢰구간 계산과 해석
- **목적**: 공식을 실제 표본 하나에 적용해보기
- **구성**: withjm TAB2 상단("1회 상세 과정") 그대로 재사용 — 표본크기 슬라이더, 신뢰도 토글, 표본 추출 버튼, 표본 강조 산점도, 계산 과정(합계→÷n→평균, ME, 신뢰구간 대입식), 신뢰구간 판정 막대
- **모평균 비공개 유지**: 판정 막대의 모평균 라벨은 아직 숫자 없이 점선만(2절 메커니즘)

### 8단계. 반복 시뮬레이션을 통한 신뢰도의 의미 확인 — 모평균 공개
- **목적**: 신뢰도의 확률적 의미("신뢰도가 높을수록 개별 구간은 넓어지지만 포함할 확률도 높아진다")를 반복으로 확인. **이 단계에서 처음으로 모평균 숫자를 공개**
- **구성**:
  1. 진입 연출: "사실 모집단은 이랬습니다"라는 안내와 함께 withjm TAB0의 히스토그램+산점도+통계량을 보여줌(재생성 버튼도 여기로 이동), `state.meanRevealed = true`로 전환
  2. withjm TAB2 하단("반복 시뮬레이션") 그대로 재사용 — 설정(표본크기, 속도), 반복 추출(1/10/100회+임의횟수), 보기 모드(95%만/99%만/비교), Error Bar 비교 차트, 성공률 게이지, 누적 성공률 그래프
- **재사용**: withjm `drawOneTrial`, `renderTab3Dashboard`, `renderTab3Charts`, `errorBarChart`, `convergenceChart`, `gauge95Chart`, `gauge99Chart` 그대로

### 9단계. 표본크기의 영향
- **목적**: 표본크기가 커지면 신뢰구간 폭이 줄어든다는 것을 확인
- **구성**: n 슬라이더(기존 재사용) 조작 시 신뢰구간 폭 변화 관찰 + "n vs 구간 폭" 추이 그래프(신규, first-task 10단계 방식 참고, Canvas 직접 구현으로 withjm 스타일 유지)

### 10단계. 새로운 상황에 적용
- **목적**: 배운 것을 다른 맥락에 전이
- **구성**: "같은 학교 1학년 학생들의 평균 통학시간(분)이 궁금하다. 1학년 300명 중 40명을 무작위로 뽑아 조사했더니 평균 통학시간이 OO분으로 나왔다." → 신뢰구간 계산 버튼 → 학교가 이 결과로 무엇을 결정할 수 있을지(예: 스쿨버스 배차 시간, 지각 방지 대책) 서술형으로 정리
- **재사용**: first-task 11단계 구조(계산 버튼 + 서술형 해석), withjm `confidenceInterval` 계산 로직

## 4. 기술 메모

- 표준정규분포 넓이 계산(6-1단계)은 외부 라이브러리 없이, 기존 `phi(x)`(PDF)를 모듈 스코프로 옮기고 수치적분(Simpson's rule 등)으로 `normalAreaBetween(z)` 구현. first-task의 `normalCDF`(Abramowitz-Stegun 근사) 방식도 참고 가능하나, withjm 스타일(외부 근사식 대신 직접 적분)을 우선 고려.
- 넓이 허용오차: 목표값과의 차이가 ±0.003 이내면 "찾음" 처리(이전 대화 합의).
- 부등식 변형 최종식 객관식 오답 후보는 구현 단계에서 설계(부호 반대, 방향 반대, √n 누락 등).
